source substitution. The complete replayed parent and both fresh reference
policies match the original source. The two minimum brackets overlap; their

The new endpoint uses 132 LP variables and 159 constraints under the unchanged
512 limits. Its LP arithmetic charge is about 72% lower for this single pinned
scenario; its compiler work is higher. These are charged solver counters, not a
wall-clock speed benchmark or a general performance prediction. The new kernel
also has analytic controls covering 2^32 continuation maps, but this physical
comparison retains exactly the original small private support.

The report retains the complete old control for inspection. It is 140,968 stored
and 1,872,520 expanded bytes, under the existing 8 MiB limits, with stored SHA-256

forced-action value remains about 0.7857792 bb, above the minimum upper bracket;

## Reproduction and safeguards

Use Java 21 and the existing solver, engine and runtime dependency classpath:

```text
com.pokerlab.solver.SixMaxRootSequenceMinimumMain solve|replay request pinned-source pinned-legacy-minimum report
mvn -pl solver -am "-Dtest=RootSequenceMinimumStudyTest,RootSequenceMinimaxTest" "-Dsurefire.failIfNoSpecifiedTests=false" test
python scripts/check-physical-root-sequence-minimum.py
python -m unittest discover -s scripts -p test_check_physical_root_sequence_minimum.py
```

The CLI rejects existing solve outputs and file aliases before physical work.
Request schemas, source hashes and the legacy byte pin are mandatory. Reads and
writes enforce both expanded and stored caps. `replay` reconstructs the entire
report, including the original parent, source policies, endpoint witnesses and
charged work, rather than accepting parsed JSON as solver ownership.

The independent checker verifies the new parent and endpoint certificates with
exact rational arithmetic on their binary64 coefficients. It reconstructs
physical terminal payouts, original recall and flow topology, conditional chance
normalization, the full security face and the forced-action domain. Original
information-set best responses and the independently checked legacy 52-plan
maximum agree with the new witness. The old control's 1,296-map coverage is
verified independently; that enumeration is not performed by the new production
kernel. Corruption controls also reject incorrect comparisons, source identity,
parent provenance, primal/dual witnesses, work claims and false failure support.

Existing trainer source pins and move EVs remain unchanged. This experiment does
not replace the current cache or improve the public trainer automatically. A
later adoption needs its own declared complete-menu, loss and admission checks;
broader private ranges and six-active-player equilibrium remain separate work.
