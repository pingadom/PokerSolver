## Using the exercise

Enable the existing [cached sequence API](sequence-preflop-cached-api.md) with its
exact manifest and study pin, then open `#root-sequence-preflop`. The page replaces
the bare route with `?study=586e0c0777ca9fa8f48e957f126a8f24c8b9382ba9da1442f684fdcb5f40ff21`
after checking server metadata. A stale, duplicated or unknown query fails closed;
"Load current study" deliberately reloads the current source.

For a Docker-enabled local environment, the existing backend overlay is:

```text
docker compose -f docker-compose.yml -f docker-compose.trainer-root-sequence-preflop.yml up --build -d
```

Run the frontend separately with `pnpm --dir frontend dev`. Its dedicated
`POKERLAB_ROOT_SEQUENCE_PREFLOP_API_TARGET` proxy defaults to
`http://localhost:18080`, the normal local API port. Set that variable in the
frontend process environment if this study uses a separate API. The opt-in does
one bounded source replay during startup; wait for the cache-enabled log before
loading practice. Without an enabled server the UI shows an error and offers a
retry. It never supplies grades from its bundled fixture.

The button has raised to 3 bb; hero BB holds pocket nines and has 2 bb to call.
All six seats remain visible with four folded players, a red villain BTN and a
blue hero BB. The public board stays empty. Move buttons show outward-rounded
server EV intervals and extra chips committed. Choose with a button or keys 1–3.
Feedback appears below the controls, with the selected move also shown at hero's
seat. It grades the current decision rather than advancing a played-out hand.

| Choice | Feedback | Meaning in this bounded study |
| --- | --- | --- |
| Fold | Outside limit | The loss exceeds the decision limit throughout its supported range |
| Call 2 bb | Within limit | The loss stays within the decision limit throughout its supported range |
| Raise to 9 bb | Unresolved | The loss interval crosses the limit; neither a proven mistake nor a proven safe move |

"Try another move" repeats this same root. "Review" asks the server to rebuild
the ordered attempt history, including repetitions; unresolved choices have
their own count. "Download session review" validates the source, choices, totals,
grades and LF document framing, then downloads the unchanged server text. The
128-attempt cap disables further choices until reset. "Start over" clears only
this study's saved attempts. Reloading restores a valid source-bound session;
unavailable browser storage leaves practice usable for the current visit.

## Source isolation and implementation

`SequencePreflopPage` supplies `sequencePreflopClient` to the existing
`RootPreflopPage`. The shared strict protocol checks every successful response
against the owned public capture. It rejects malformed payloads, wrong source
pins, unexpected grades and altered review/export content. The capture is copied
byte-for-byte from `docs/data/supplied-sequence-preflop-drill-fixture.json`; CI
checks equality before installing frontend dependencies. No source evidence or
backend algorithm changes are part of this UI adoption.

The browser's independent session key is
`pokerlab:root-sequence-preflop:v1:586e0c0777ca9fa8f48e957f126a8f24c8b9382ba9da1442f684fdcb5f40ff21`.
The original `#root-preflop` and minimum-informed `#root-minimum-preflop` routes
retain their source pins, labels and keys. Changing studies aborts pending
requests and ignores late replies. All three study links remain in the solver
section. The new configurable study label changes presentation only.

EVs already include the server's single 1 bb commitment adjustment; browser code
does not shift them again. The raise's lower EV endpoint is approximately
1.2111418188 bb, its full-action ceiling remains approximately 1.7857792830 bb,
and its upper loss remains approximately .5746374641 bb. The minimum endpoint
bracket is not substituted for the full-action ceiling. The source's tiny fold
certificate tolerance and full binary64 values remain available under the scope
details. Separate EV endpoints cannot be subtracted to reconstruct joint losses.

## Remaining scope

This release exposes one repeated root with supplied ranges, selected-future-flop
continuations and public trainer admission false. It does not add more hands,
randomize streets, play out a full hand, establish unique action frequencies or
solve all six players' unrestricted strategies. Broader source qualification and
additional playable scenarios remain separate backend work.
