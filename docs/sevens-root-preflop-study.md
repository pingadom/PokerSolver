## Run the declared study

The CLI accepts four arguments:

```text
SixMaxSevensRootMain solve|replay request.json pinned-parent.json.gz report.json.gz
```

Use `docs/data/supplied-sevens-root-study-request.json` and the existing
`docs/data/supplied-flop-size-menu-report.json.gz`. `solve` reserves a new output
before work and refuses aliases/overwrites; `replay` requires complete equality
with `docs/data/supplied-sevens-root-study-report.json.gz`. Both operations perform
the declared physical work; they are offline research commands, not HTTP routes.
Malformed requests, foreign parent bytes or changed parent inputs fail before
optimization. Sources are checked again after work. The separate stdlib command
below verifies saved evidence without LP optimization or CFR training:

```text
python scripts/check-sevens-root-study.py
```
