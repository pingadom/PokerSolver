## Ownership and reproduction

`SixMaxRootSequenceFeedback.solve` reads the pinned sequence minimum and original
envelope before asking the existing physical study to reproduce its complete
report, including its parent, references and endpoint. The study independently
rechecks the original envelope and legacy bytes before physical work. Equality
of the entire saved report is mandatory before qualification. Report parsing
alone cannot create `Result` or `QualifiedFeedback`; their constructors are
private. The qualification object binds the full derived report's canonical hash.
An incomplete minimum aborts feedback derivation; unsupported assessments retain
their original failures and grant no qualification.

The CLI is `com.pokerlab.solver.SixMaxRootSequenceFeedbackMain`, with six arguments:

```text
solve|replay feedback-request original-envelope legacy-minimum sequence-minimum feedback-report
```

Existing outputs, normalized aliases and actual hard links are rejected before
physical work. New output uses CREATE_NEW. Sources are bounded and byte-pinned;
stored and expanded output caps apply. Full feedback replay checks every derived
field, not only the report hash. Source and existing numerical-kernel code are
unchanged.

```text
mvn -pl solver -am "-Dtest=RootSequenceFeedbackTest,RootMinimumFeedbackParsingTest" "-Dsurefire.failIfNoSpecifiedTests=false" test
python scripts/check-root-sequence-feedback.py
```
