## Physical result

The one declared generation completed without retry or a limit change. The batch
used one owned parent/two parent LPs and three endpoint LPs, rather than repeating
two parent LPs for each action. The separate original parent/reference replay adds
two parent LPs to the study as a whole. This is a solve-count comparison for this
fixed model, not a wall-clock speed claim.

| Original BB99 action | Minimum lower bracket (BB) | Minimum upper bracket (BB) | Endpoint pivots | Endpoint arithmetic units |
| --- | ---: | ---: | ---: | ---: |
| Fold | -1.0000000100 | -0.9999999900 | 35 | 284,229,735 |
| Call | 0.7857791903 | 0.7857792103 | 39 | 314,569,051 |
| Raise to 9 | 0.2111418188 | 0.2111418388 | 73 | 572,344,163 |

These values are terminal profit in BB from the original game. They include the
posted blind. The existing trainer's current-decision convention adds one BB; this
research report does not apply that display conversion. Each row separately
minimises the best forced-action continuation over the same global opponent
security face. Its upper bracket bounds that minimum, not every possible strategy's
value for that action. The three row witnesses need not be one joint policy.

The batch charged 6,126,441 of 8,000,000 endpoint compiler units, including 4,827
question-preflight visits; 147 of 10,000 endpoint pivots; and 1,171,142,949 of
4,000,000,000 endpoint arithmetic units. Its parent separately charged 1,036,207
compiler units and 179,650,457 LP arithmetic units. Every endpoint receives the
remaining cumulative limits. No continuation plans were enumerated. Each physical
endpoint LP has 132 variables and 159 constraints, with original flows of 85 hero
and 121 opponent sequences.

Fold reproduces the old conservative lower bound. Call differs from it only by
binary64 rounding (about 1.1e-16 BB). Raise improves the original conservative lower
bound by 6.5705760310 BB and reproduces the complete prior sequence minimum audit,
allowing only the advertised remaining compiler limit to differ. This study adds
physical evidence for the complete menu and shared-parent work accounting; it does
not improve the previously published raise minimum or expand the source ranges.

All nine checks of the primary policy and the fresh 80k/160k reference policies
against the three lower bounds passed. All original whole-parent and public-root
assessments remain identical. In particular, a primary policy's raise utility can
exceed the raise minimum's upper bracket without failing a lower-bound check.
